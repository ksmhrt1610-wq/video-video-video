# VVV Editor — ブラウザで動く Premiere Pro ライクな動画編集ソフト

Adobe Premiere Pro の「編集」ワークスペースを参考にした、ノンリニア動画編集ソフトです。
React + TypeScript + Vite で作られており、**インストール不要・ブラウザだけで動作**します。
素材はどこにもアップロードされず、すべてローカル（ブラウザ内）で処理されます。

## 起動方法

```bash
npm install
npm run dev        # http://localhost:5173 を開く
```

本番ビルド:

```bash
npm run build      # dist/ に静的ファイルを出力（任意の静的ホスティングに置けます）
npm test           # タイムライン編集ロジックのユニットテスト
```

推奨ブラウザ: 最新の Chrome / Edge（MP4 書き出しに対応）。Firefox は WebM 書き出しになります。

## 画面構成（Premiere Pro と同じ配置）

| 位置 | パネル |
| --- | --- |
| 左上 | **ソース**モニター / **エフェクトコントロール** |
| 右上 | **プログラム**モニター + オーディオメーター |
| 左下 | **プロジェクト** / **エフェクト** / **グラフィック** |
| 右下 | ツール + **タイムライン** |

パネルの境界はドラッグでサイズ変更できます。

## 主な機能

### 素材の読み込み
- 動画（MP4 / WebM / MOV など）・音声（MP3 / WAV / OGG など）・画像に対応
- プロジェクトパネルへのドラッグ＆ドロップ、またはタイムラインへ直接ドロップ
- サムネイル（フィルムストリップ）と音声波形を自動生成
- 最初に読み込んだ動画に合わせてシーケンスの解像度を自動設定

### タイムライン
- 複数の映像トラック（V1, V2, …）と音声トラック（A1, A2, …）。上のトラックが前面に合成されます
- 音声付き動画は **映像＋音声のリンククリップ** として配置（Alt クリックで片方だけ操作）
- クリップの移動（トラック間も可）、端のドラッグによるトリム、**上書き**配置
- **レーザーツール**（C）で分割、Shift+クリックで全トラックを分割
- **リップル削除**、ギャップのリップル削除、**Q / W のリップルトリム**
- スナップ（S）、マーカー（M）、範囲選択（ドラッグ）、コピー＆ペースト、複製
- クリップの有効／無効（Shift+E）、リンク／リンク解除
- トラックの表示切り替え・ミュート・ロック、トラックの追加・削除
- Ctrl+ホイールでズーム、`\` で全体表示

### ソースモニター
- 素材をダブルクリックで開き、**イン点（I）／アウト点（O）** を設定
- **インサート（,）** / **上書き（.）** 編集、またはイン〜アウト範囲をタイムラインへドラッグ

### エフェクトコントロール
- **モーション**: 位置・スケール・回転（プログラムモニター上で直接ドラッグして移動も可）
- **不透明度** と **描画モード**（乗算・スクリーン・オーバーレイなど）
- **カラー補正**: 明るさ・コントラスト・彩度・色相・モノクロ・セピア・反転・ブラー
- 各値の **キーフレームアニメーション**（ストップウォッチ、キーフレームの追加・削除・移動）
- **速度・デュレーション**（10%〜1000%）
- **オーディオ**: ボリューム・パン・フェードイン／アウト
- 値は青い数字を左右にドラッグして調整（Premiere の「ホットテキスト」と同じ操作）

### トランジション・プリセット
- クロスディゾルブ、暗転、ホワイトアウト、ワイプ、スライド、プッシュ、ズーム
- クリップの左半分にドロップで開始側、右半分で終了側に適用
- 開始側トランジションは同じトラックの直前のクリップから切り替わります
- プリセット: モノクロ、セピア、ビビッド、シネマ調、ケン・バーンズ（ズームイン／アウト）、パン など

### グラフィック
- テキスト（タイトル・字幕・ロワーサード・インパクト）とカラーマット
- フォント、サイズ、太字／斜体、揃え、塗り・境界線・背景・シャドウ

### 書き出し・保存
- **MP4（H.264/AAC）** または **WebM** で書き出し（品質を選択可能）
- 現在のフレームを PNG で保存
- プロジェクトと素材はブラウザ（IndexedDB）に **自動保存** され、再読み込みしても復元されます
- 取り消し／やり直し（最大 200 ステップ）

## キーボードショートカット

| キー | 操作 |
| --- | --- |
| Space / K / L / J | 再生・停止 / 停止 / 再生 / 5 秒戻る |
| ← / → | 1 フレーム移動（Shift で 5 フレーム） |
| ↑ / ↓ | 前 / 次の編集点 |
| V / C / H | 選択 / レーザー / 手のひらツール |
| Ctrl+K | 再生ヘッドで分割 |
| Q / W | 前 / 次をリップルトリム |
| Delete / Shift+Delete | 消去 / リップル削除 |
| Ctrl+C / X / V / D | コピー / カット / ペースト / 複製 |
| Ctrl+Z / Ctrl+Shift+Z | 取り消し / やり直し |
| I / O / , / . | イン / アウト / インサート / 上書き |
| M / S / T | マーカー / スナップ / テキスト追加 |
| + / - / \ | ズームイン / アウト / 全体表示 |
| Ctrl+I / Ctrl+M | 読み込み / 書き出し |

アプリ内の「ヘルプ → キーボードショートカット」（`?`）でも確認できます。

## 制限事項

- 書き出しはリアルタイム（シーケンスの長さと同じ時間）で行われます。書き出し中はタブを前面に表示したままにしてください。
- 再生できる形式はブラウザに依存します（例: H.265 / ProRes は多くのブラウザで非対応）。
- 速度変更時、音声のピッチは保持されません。
- 非常に大きなファイルは音声波形の解析にメモリを多く使用します。

## ソース構成

```
src/
  core/
    types.ts      データモデル（プロジェクト・トラック・クリップ）
    timeline.ts   タイムライン編集ロジック（上書き・分割・リップル・トリム・スナップ）
    props.ts      エフェクトのパラメーター定義とキーフレーム補間
    render.ts     フレーム合成（変形・カラー・描画モード・トランジション・テキスト）
    engine.ts     再生エンジン（映像同期・WebAudio 再生・書き出し）
    media.ts      読み込み・サムネイル・波形解析
    persist.ts    IndexedDB への自動保存
  components/     各パネルの UI
  actions.ts      編集コマンド
  store.ts        状態管理と取り消し／やり直し
  shortcuts.ts    キーボードショートカット
```
